# Плагин jgrep-agent для Codex

jgrep-agent предлагает агентам программирования сначала находить код через
компактный вывод jgrep. Это позволяет читать только нужные диапазоны
исходного текста и уменьшает объём вывода инструментов.

## Установка

В Codex добавьте локальный marketplace этого репозитория и установите плагин:

~~~sh
codex plugin marketplace add xxvw/jgrep --ref main --sparse .agents/plugins --sparse plugins/jgrep-agent && codex plugin add jgrep-agent@jgrep
~~~

После установки начните новую сессию Codex. Затем установите исполняемый файл
jgrep по инструкциям в [основном README](https://github.com/xxvw/jgrep/blob/main/README.md) или в
[руководстве по установке и агентам](https://github.com/xxvw/jgrep/blob/main/docs/installation-and-agents.md).

## Рабочий процесс агента

Используйте --ai для первого поиска. Каждое совпадение — это компактный
указатель без текста исходного кода:

~~~sh
jgrep --ai --ai-max-results 25 -r -F 'validate_session' src/
jgrep --ai --ai-max-results 25 -r -E 'TODO|FIXME' src/
jgrep --ai --ai-max-results 25 -r --include '*.rs' \
  'где обрабатываются ошибки аутентификации' src/
~~~

Разбирайте запись по завершающей части `:LINE`: это последнее двоеточие перед
десятичным номером строки. Не разделяйте по первому двоеточию, потому что путь
Windows может, например, начинаться с `C:\`. `-:LINE` обозначает стандартный ввод
из воспроизводимого конвейера.

Для известных символов или фиксированного текста используйте -F, а для
шаблонов регулярных выражений — -E. Оба режима выполняют точный лексический
поиск и не загружают модель. Семантический поиск --ai предназначен для
описаний поведения и понятий.

По умолчанию выводится не более 50 указателей. Если jgrep сообщает в stderr о
достижении ограничения, результат неполный: сузьте запрос или каталог, прежде
чем увеличивать --ai-max-results. После поиска читайте только указанные
диапазоны строк.

Если jgrep не установлен или компактный поиск не может выразить запрос,
используйте rg как запасной вариант:

~~~sh
rg -n -F 'validate_session' src/
~~~
